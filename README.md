# Ram Laxman Shastry Jagarlapudi — Portfolio

Static portfolio site (HTML/CSS/JS, no build step). Open `index.html` directly, or host on GitHub Pages.

## Structure
- `index.html`, `style.css`, `main.js` — main site (dark/light, responsive)
- `projects/enterprise-rag/` — Enterprise Knowledge Intelligence Platform (project page + demo)
- `projects/research-agents/` — Multi-Agent Research & Decision Intelligence System (project page + demo)
- `projects/dashboard-hub/` — Dashboard Hub

## Run locally
Double-click `index.html`, or `python -m http.server 8080` and open http://localhost:8080.

## Deploy (GitHub Pages)
1. Create a repo named `Laxman8737.github.io` (site at https://laxman8737.github.io) or any name (site at /<repo>/).
2. Upload these files to the repo root and push to `main`.
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.

The two GenAI project pages run in recorded-demo mode on Pages (real captured outputs). Run each project repo locally for the live API.
