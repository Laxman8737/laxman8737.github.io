ARCHITECTURE

Query + role→Injection guard→ACL pre-filter→BM25 ∥ Dense→RRF fusion→Reranker→Abstain gate→Cited generation→Citation verify

Orchestrated as a LangGraph state graph (sequential fallback if not installed). Cache keyed by query+roles+mode; every call is token/cost-tracked. Production storage: PostgreSQL + pgvector (db/schema.sql).

LIMITATIONS

  • Reference backends are offline (hashed n-gram vectors, lexical reranker, extractive generator) so the repo runs anywhere; neural embeddings/cross-encoder/LLM are opt-in via env vars and have not been benchmarked in the bundled report.
  • Eval corpus is small and synthetic, with sentence-level facts — it does not capture long documents, tables, PDFs or noisy OCR.
  • Roles come from the request body in the demo. Production must derive roles from a verified identity token (OIDC/JWT).
  • Injection defense is pattern-based plus context delimiting; it will miss novel or obfuscated attacks. Add an LLM classifier and output filtering for high-risk use.
  • Abstain threshold is an untuned default: it blocks unanswerable questions but also rejects some paraphrased answerable ones.
  • The demo index is in-memory; the pgvector schema is provided but the Postgres adapter is not implemented in this bundle.
