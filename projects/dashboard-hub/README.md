# Dashboard Hub

A Groww-style account area that combines two dashboards:

- **Project Portfolio Management Dashboard**
- **Business Performance Analytics Dashboard**

Flow: Sign up -> Create profile -> Home (combined overview) -> open either dashboard -> edit profile / log out.

## Run
Open `index.html` in a browser. Everything is in that one file.

## GitHub Pages
Settings -> Pages -> Deploy from a branch -> main / (root).

## Note
This is a front-end demo. Accounts are stored in the browser's localStorage and passwords are only lightly encoded, so don't use a real password. A production app needs a real backend (e.g. Firebase Auth or Supabase).
