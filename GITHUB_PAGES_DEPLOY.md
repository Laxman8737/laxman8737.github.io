# Portfolio website — GitHub Pages

This folder is the complete static portfolio site.

## Publish
1. Extract this ZIP.
2. Upload the **contents of this folder** to the root of your portfolio GitHub repository (not the enclosing folder).
3. Ensure `index.html`, `style.css`, `main.js`, `profile.jpeg`, and `favicon.png` are at the repository root.
4. In GitHub, open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Wait for the deployment to finish and open the Pages URL.

Project cards now have only two buttons: **GitHub** and **Live Demo**. Live demos link to the three URLs provided. Skills are displayed as wide, compact rows stacked vertically.
